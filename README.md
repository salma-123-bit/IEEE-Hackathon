# 🎨 Yuzersef (يوزرسيف) - Custom Printing & Personalization Platform

> **IEEE Aswan Student Branch - Brand & Build Competition Project**[cite: 2]

Welcome to **Yuzersef** (يوزرسيف)—a full-stack, custom-built web application designed for an Aswan-based printing and personalization business[cite: 3]. The platform streamlines customer requests, replacing scattered chats with an organized, end-to-end web journey[cite: 3, 7].

## 🛠️ Tech Stack & Development Tools

This project was brought to life using a modern ecosystem of development tools, design apps, and AI assistants:

*   **Development Environment:** 
    *   **Antigravity IDE:** The primary coding workspace and environment.
*   **Version Control & Deployment:**
    *   **Git & GitHub:** For source code management, version control, and repository hosting.
    *   **Vercel:** For seamless live production hosting and deployment.
*   **Design & Visuals:**
    *   **Figma & Canva:** Used for UI/UX wireframing, layout planning, and promotional graphic assets.
*   **AI Development Co-pilots:**
    *   **Google Gemini & ChatGPT:** Core assistants for code logic generation, debugging, and user experience planning.
    *   **Claude, Stitch, & Manus:** Utilized for advanced architectural structuring, code refinement, and workflow scoping.
*   **Frontend Technologies:**
    *   **React & Vite:** For building a fast, interactive single-page application.
    *   **TypeScript:** To ensure code safety and type integrity.
    *   **Tailwind CSS / Custom CSS:** For responsive styling and clean layouts with full Arabic RTL support[cite: 10].

---

## 🚀 Key Features Implemented

*   **Product Catalogue & Customization:** Supports custom printing for T-shirts, hoodies, mugs, phone cases, stickers, caps, and promotional gifts with specific options and size breakdowns[cite: 3, 7].
*   **Request-Readiness Assistant (Distinctive Feature):** Intelligently flags missing specifications or mismatched quantities before submission to optimize the owner's workflow[cite: 7, 9].
*   **End-to-End Request Flow:** Guides customers from product selection and artwork uploading to final order submission and tracking[cite: 6, 7].
*   **Protected Admin Dashboard:** Gives the business owner a clean workspace to inspect customer files, view request details, and issue approvals or rejections[cite: 6, 8].
