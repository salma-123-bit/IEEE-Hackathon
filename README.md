#  Yuzersef (يوزرسيف) - Custom Printing Platform

Hey everyone! Welcome to **Yuzersef**—a custom-built web application designed for ordering personalized print products like T-shirts, hoodies, mugs, phone cases, and more. It features real-time product mockups, live previews, and order tracking to make custom printing seamless.

---

##  How I Built This (Tech Stack & Tools)

Building this project was an awesome learning experience. Here are the tools, technologies, design apps, and AI assistants that helped bring it to life:

*   **Development Environment & Editors:**
    *   **Antigravity IDE:** The coding environment and workspace where I wrote and organized all the project files.
*   **Version Control & Hosting:**
    *   **Git & GitHub:** For keeping track of my code and hosting the repository.
*   **Design & Visual Assets:**
    *   **Canva:** Used for creating visual layouts, promotional assets, and graphic elements.
    *   **Figma:** For UI/UX design planning, wireframing, and shaping the look and feel of the app.
*   **AI Development Partners & Assistants:**
    *   **Google Gemini:** My go-to for writing code snippets, explaining complex logic, and debugging.
    *   **ChatGPT:** Helped me brainstorm features, plan the project structure, and refine the user experience.
    *   **Claude:** Assisted with code logic, refinement, and technical writing.
    *   **Stitch & Manus:** Helped with project scoping, architecture planning, and setting up core workflows.
*   **Frontend Technologies:**
    *   **React & Vite:** For building a fast, interactive, and smooth user interface.
    *   **TypeScript:** To keep the code clean, typed, and error-free.
    *   **Tailwind CSS / Custom CSS:** For styling the responsive layouts and making it look sleek.
